FOGMONITOR by FOGLABS — PORTABLE WINDOWS BUILD

1. Estrai tutti i file dello ZIP in una cartella normale.
2. Avvia FogMonitor.exe con un doppio clic.
3. Non serve installare Python sul PC per usare questa versione compilata.

Le metriche sono lette localmente. I dati non vengono inviati online.
La disponibilita del contatore GPU dipende da Windows e dal driver video.
Le temperature CPU/GPU non sono disponibili tramite le API generiche usate.

Log diagnostico (se necessario):
%LOCALAPPDATA%\FogLabs\FogMonitor\FogMonitor-error.log
