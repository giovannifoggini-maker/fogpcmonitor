not the desktop app.

FogMonitor is a Windows desktop application written in Python and Tkinter. Cloudflare Pages can host its static landing page and source downloads, but it does not build a Windows .exe.

Cloudflare Pages settings

Use these exact settings for a Git-connected Pages project:

  • Framework preset: None
  • Root directory: repository root (leave blank)
  • Build command: exit 0 (or leave blank for static files)
  • Build output directory: public
  • Environment variables: none required

The repository must contain public/index.html. This project includes it, plus styles, scripts, an icon and a downloadable source ZIP.

Build the Windows application

  1. Use the Build-EXE.bat script on Windows, or push the repository to GitHub.
  2. In GitHub, run Actions → Build Windows release, or create a version tag such as v1.7.0.
  3. Download the generated FogMonitor-by-FogLabs-Windows.zip artifact from the workflow or release.

Cloudflare’s build pipeline publishes only the files in public/; it is separate from the Windows packaging workflow.
